### 🚀 What I've Worked On
- **[Hackintosh EFI for Thinkpad X1 Carbon](https://github.com/saku-bruh/ThinkPad-X1-Carbon-G4-OpenCore):** Custom OpenCore configuration for running macOS Tahoe on the 4th Gen X1 Carbon.
- **[Hackintosh EFI for Thinkpad X1 Carbon](https://github.com/saku-bruh/Thinkpad-T420-Opencore):** Custom OpenCore configuration for running macOS Sequoia on the T420.
- **[LuCI Theme Material 3](https://github.com/saku-bruh/luci-theme-material3):** A sleek Bootstrap theme bringing Material Design 3 to LuCI.
- **[Maemo Leste Optimizations](https://github.com/saku-bruh/n900-leste):** Performance tweaks and system optimizations for Maemo Leste on the Nokia N900.
- **[N900 U-Boot](https://github.com/saku-bruh/N900-UMBoot):** A repo that archived multiboot environment allowing switching between Maemo 5/postmarketOS/Maemo Leste & Maemo 5/Android (NITDroid) for the Nokia N900, made this since the CSSU (Nokia N900 repo that you could've used to do a cleaner installed) I've seen it come up but I haven't had time to try it and allegedly it doesn't have all the packages?
- **[sakuPS](https://github.com/saku-bruh/sakuPS):** Old TS server fork for a certain anime game
- **[CWWepe](https://github.com/saku-bruh/CWWepe):** Yet another old funny http server script for another certain anime game
